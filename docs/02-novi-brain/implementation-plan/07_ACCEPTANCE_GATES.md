# 07 — Acceptance Gates

## Gate G0 — Architecture

Architecture specifications, ownership boundaries and canonical contracts exist and are internally consistent.

**Status:** PASS / historical baseline.

## Gate G1 — Deterministic Runtime

Runtime components, contracts, tests and CI validation pass without requiring production hardware.

**Status:** PASS / historical baseline.

## Gate G2 — Real Neural Capability

Each selected model executes on real hardware and satisfies capability, output-contract, resource and latency requirements for its intended role.

**Status:** OPEN.

## Gate G3 — Full Neural Pipeline

Perception, multimodal understanding, physical reasoning, world state and Brain orchestration operate concurrently with bounded latency and valid provenance.

**Status:** OPEN.

## Gate G4 — Hardware Selection

Orin 64GB and Thor have been evaluated using equivalent Novi workloads and a formal decision record has selected one platform or explicitly rejected both.

**Status:** OPEN.

## Gate G5 — Closed-Loop Integration

The validated neural stack operates inside the existing Brain closed loop without bypassing safety, autonomy or execution ownership.

**Status:** OPEN.

## Gate G6 — B2 Completion

All B2 acceptance criteria pass, evidence is archived, the completion tracker is synchronized and known limitations are recorded.

**Status:** OPEN.

## Gate discipline

A gate cannot be marked PASS based solely on implementation existence. Each gate requires the evidence defined by its associated workstream.
