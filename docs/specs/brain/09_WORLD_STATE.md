# Mac Brain World State

## Objective

Maintain a structured, time-aware representation of what Novi currently believes about its environment and internal state.

## State categories

- entities;
- locations/relationships;
- events;
- sensor observations;
- active goals;
- active plans;
- confidence/uncertainty;
- timestamps/freshness;
- provenance;
- system health.

## Rules

World state is derived from validated evidence. Neural outputs are not automatically trusted. Conflicting or stale evidence must remain visible and bounded.
