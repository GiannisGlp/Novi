# Mac Brain Reasoning

## Objective

Provide model-assisted reasoning capabilities while keeping reasoning outputs explicit, bounded and auditable.

## Candidate roles

- Nemotron: multimodal understanding and interpretation.
- Cosmos Reason2: physical/spatiotemporal reasoning.
- Specialist models: perception evidence.

## Reasoning contract

Input contains validated observations, relevant memory and task/goal context. Output is structured reasoning evidence with correlation, uncertainty where available and a clear distinction between observation and inference.

## Rule

Reasoning must not fabricate sensor facts or silently overwrite authoritative world state.
