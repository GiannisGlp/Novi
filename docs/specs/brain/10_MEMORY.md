# Mac Brain Memory

## Objective

Allow Novi to retain and retrieve information that is useful for cognition while distinguishing current observations from remembered information.

## Initial layers

- working/short-term context;
- episodic events;
- durable semantic facts where explicitly justified.

## Memory rules

Memory entries carry provenance, timestamp, source and confidence where applicable. Current sensor evidence can supersede stale remembered state. Memory retrieval must be observable and testable.

## Privacy

Local microphone/camera-derived data should remain local by default. Retention must be intentional and configurable.
