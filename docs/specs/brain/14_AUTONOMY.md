# Mac Brain Autonomy

## Objective

Demonstrate bounded autonomous behavior in a controlled Mac environment.

## Autonomy loop

```text
observe -> assess -> choose -> plan -> validate -> act -> verify -> continue/stop
```

## Initial autonomous capabilities

- continuous observation;
- event detection;
- goal pursuit;
- plan execution through virtual actions;
- replanning;
- timeout handling;
- stop/cancel;
- degraded operation.

## Boundaries

Autonomy is constrained by deterministic policy and safety checks. No model may create unrestricted operating-system or physical commands.
