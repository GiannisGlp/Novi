# Mac Brain Scenario Catalog

## Initial scenarios

- `SC-001` First contact — camera + speech + response.
- `SC-002` Object recognition — identify objects and preserve evidence.
- `SC-003` Conversation — speech, context and multimodal answer.
- `SC-004` Memory — remember and retrieve a relevant fact.
- `SC-005` Scene change — detect and explain meaningful change.
- `SC-006` Goal execution — accept a bounded goal and execute virtual steps.
- `SC-007` Replanning — change plan after new evidence.
- `SC-008` Uncertainty — respond appropriately to ambiguous evidence.
- `SC-009` Failure recovery — survive model/device failure.
- `SC-010` Continuous operation — run repeated observe/reason/act cycles.

## Scenario format

Each scenario must define initial state, inputs, expected observations, expected world-state changes, allowed actions, safety constraints, success criteria and evidence requirements.
