# Sensors Implementation Workstream

## Scope

Cameras, IMU, LiDAR/range sensing, audio and other sensors required by Novi, including calibration, synchronization and health monitoring.

## Planned progression

1. Define sensor requirements from robot capabilities.
2. Select candidate sensors.
3. Define time synchronization and calibration.
4. Implement drivers and normalized sensor contracts.
5. Validate sensor quality and failure behavior.
6. Integrate with perception/localization/mapping.
