# Novi Evidence Program

Evidence is a first-class output of implementation and validation.

## Required evidence categories

- model capability evidence;
- perception accuracy evidence;
- performance/latency evidence;
- resource and thermal evidence;
- hardware comparison evidence;
- integration evidence;
- failure/degraded-mode evidence;
- system acceptance evidence;
- decision records.

## Rules

Every evidence package must identify the exact implementation/model/configuration/hardware/dataset under test. Conclusions must be traceable to run identifiers and raw measurements.
