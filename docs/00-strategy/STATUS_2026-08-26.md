## 1. Why this document exists

The 2026-08-19 tracker describes a *documentation-first* program ("no implementation until all 12 domains are COMPLETE"). The repository has since moved into **implementation**, and the tracker's structure/status claims have diverged from the code. This document is the single place that states what is *actually* true today, so the tracker and the code stop contradicting each other.

Rule: **the code is the source of truth for implementation state; this document records it.** When a domain doc and the code disagree, the code wins and the doc is marked SUPERSEDED.

## 2. Repository structure — UNIFIED

- The old `MAC_BRAIN/` + `brain/` split is **gone**. There is a single package: **`novi/brain/`** (80 modules).
- No top-level `MAC_BRAIN/` or `brain/` directories exist.
- The `b1_*` modules (`b1_cognition.py`, `b1_memory.py`, `b1_world.py`, `b1_autonomy.py`, `b1_execution.py`, `b1_loop.py`, `b1_outcomes.py`) still exist and are re-exported from `novi/brain/__init__.py`. Any document that still describes `MAC_BRAIN/` or a `brain/`-vs-`MAC_BRAIN/` split is **SUPERSEDED** on that point.

## 5. Technology posture (unchanged, deliberate)

- **Stdlib-first core, no web framework, no cloud LLM.** Optional heavy deps (Ollama, whisper, torchvision, sentence-transformers) are imported lazily and degrade to explicit SKIP/fallback, never a crash.
- **Single canonical DB** (`novi/data/novi.db`); new tables, never new databases.
- **Fail-closed safety** (governance guard, typed contracts, provenance).

These are positive baselines to preserve — see the gap analysis §5.
