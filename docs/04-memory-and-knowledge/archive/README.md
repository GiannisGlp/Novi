# Archived Memory & Knowledge Documentation

**Status: ARCHIVED — NON-NORMATIVE**

This directory contains historical Memory and Knowledge architecture documents preserved for design provenance, traceability, research, and future reference.

## Authority rule

These files **do not define the current Novi architecture**.

For implementation and current design decisions, use:

`docs/04-memory-and-knowledge/ARCHITECTURE_INDEX.md`

and the active canonical `01`–`18` documents.

## Why the archive exists

The historical documents contain earlier architecture generations, detailed design decisions, examples, requirements, failure cases, and research-derived ideas. They are retained rather than deleted so that Novi can recover the reasoning behind architectural decisions without allowing historical specifications to become competing authority.

## Disposition

Historical files are preserved here after consolidation. Their content has been classified and mapped through the source-material registry. Where a document contained implementation concerns belonging elsewhere, the canonical architecture records the responsibility boundary.

## Important distinction

```text
ARCHIVE = historical / traceability / reference
ACTIVE  = current normative architecture
```

Do not implement directly from an archived document without first reconciling it with the current canonical architecture.
