# Localization Implementation Workstream

## Scope

Estimate Novi's pose and motion state using appropriate sensor inputs, state estimation and validated uncertainty.

## Planned progression

1. Define localization requirements and coordinate frames.
2. Define sensor inputs and timing requirements.
3. Establish baseline odometry/state estimation.
4. Evaluate visual/inertial and other localization candidates.
5. Validate drift, recovery and failure behavior.
6. Integrate localization with mapping and navigation.
