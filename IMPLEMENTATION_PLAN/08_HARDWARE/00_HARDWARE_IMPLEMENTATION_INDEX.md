# Hardware Implementation Workstream

## Scope

Compute platform, embedded hardware, mechanical interfaces, power delivery, storage and physical integration.

## Current compute candidates

- Jetson AGX Orin 64GB — candidate.
- Jetson AGX Thor — candidate.

The compute decision is governed by the hardware evaluation plan and must be evidence-based.

## Planned progression

1. Define system-level hardware requirements.
2. Identify candidate compute and peripheral platforms.
3. Validate sensor/actuator interfaces.
4. Benchmark compute candidates using the same Novi workload.
5. Validate power, thermal and physical constraints.
6. Select hardware through a formal decision record.
