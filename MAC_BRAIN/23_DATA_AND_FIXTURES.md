# Mac Brain Data and Fixtures

## Objective

Provide repeatable inputs for development and regression while supporting real camera/microphone operation.

## Data classes

- live sensor streams;
- recorded sensor sessions;
- synthetic scenarios;
- expected state transitions;
- expected action outcomes;
- model evaluation datasets.

## Rules

Use versioned manifests and retain provenance. Sensitive camera/audio recordings should remain local by default and require explicit retention policy.
