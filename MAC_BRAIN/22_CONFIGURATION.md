# Mac Brain Configuration

## Objective

Keep model, device, timing and autonomy settings explicit and reproducible.

## Configuration categories

- device selection;
- camera/audio parameters;
- model provider and artifact identity;
- model thresholds;
- timing/deadline budgets;
- memory retention;
- goal/autonomy policy;
- logging/evidence;
- safety limits.

## Rule

No critical behavior should depend on undocumented environment variables or hard-coded developer-machine assumptions.
