# Mac Brain Evidence

## Evidence types

- model/provider runs;
- camera/audio observations;
- world-state transitions;
- memory operations;
- reasoning results;
- goal/plan transitions;
- action proposals/results;
- scenario outcomes;
- failure/recovery outcomes;
- performance/soak results.

## Minimum provenance

Commit SHA, configuration identity, provider/model identity, scenario ID/version, environment metadata, timestamps, result and relevant logs/metrics.

## Relationship

Mac Brain evidence is a program-specific view of the global `IMPLEMENTATION_PLAN/EVIDENCE` system and must use compatible provenance conventions.
