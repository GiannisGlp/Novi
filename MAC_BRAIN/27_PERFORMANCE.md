# Mac Brain Performance

## Objective

Measure whether the Mac prototype can operate continuously at useful responsiveness.

## Metrics

- sensor capture latency;
- perception latency;
- speech-to-text latency;
- model time-to-first-result;
- reasoning latency;
- end-to-end cycle latency;
- queue depth;
- memory usage;
- CPU/GPU usage where available;
- dropped frames/events;
- deadline misses.

## Rule

Mac performance results are software/prototype evidence only. They do not determine Orin/Thor selection or represent Jetson performance.
