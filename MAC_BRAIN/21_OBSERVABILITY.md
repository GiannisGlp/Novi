# Mac Brain Observability

## Objective

Make every meaningful Brain cycle inspectable and reproducible.

## Capture

- structured events;
- model invocation metadata;
- latency;
- state transitions;
- memory operations;
- goals/plans;
- action proposals/results;
- failures;
- resource usage where available;
- scenario/run identifiers.

## Human debugging

Provide a concise live status view and machine-readable evidence output. Avoid making logs the only source of truth.
